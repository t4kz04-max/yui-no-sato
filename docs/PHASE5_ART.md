# Phase 5 アート設計：3Dグラフィックとアセットの本格制作

最終更新：2026-10-14（実装前に作成し、実装後に結果を追記）

基準：PHASE_PLAN §9、GAME_DESIGN L 節（ビジュアル方針）、ユーザー指示（2026-10-14）。
目的：白川郷の合掌造りと、住民どうしの協力が、ゲームの世界の中で自然に伝わる見た目にする。システム・シナリオは変えない。

## 0. 方針

- **外部素材は使わない。** 形はすべて Three.js の基本形状と、コードで生成するジオメトリ・テクスチャ（Canvas に描く茅の繊維など）で作る。ライセンスの管理対象を増やさない。
- **見た目の作り込みより、遊びやすさを優先する。** 名前のある住民 5 人は鮮やかで互いに違う色、名前のない村の人たちは落ち着いた色にして、背景に埋もれないようにする。装飾は、道と、調べられる物・住民の周りを避けて置く。
- **状態と描画を分ける。** 「どの屋根がどの状態か」「当日に誰が何の役割でいるか」は、物語の状態から純粋関数で決める（`src/content/staging.ts`）。描画側はそれを受け取って表示するだけ。
- **確証のない装飾は付けない。** 合掌造りについて広く知られている特徴（急勾配の茅葺き屋根、厚い茅の軒先、妻面の多層の窓、木の躯体と障子、石の土台）だけを表現する。村は架空で、史跡の復元ではない（GAME_DESIGN L）。時代設定は未確定なので、服装は時代を特定しない素朴な野良着の形にする。

## 1. 建物

| 項目 | 内容 |
|---|---|
| 屋根の形 | 急勾配（約58°）の切妻。厚み 0.9m 前後の茅を、上面・裏面・軒先の切り口・妻側の端まで作る |
| 茅の質感 | Canvas で生成した繊維のテクスチャ（流れ方向に筋）＋頂点色で層の帯・色むら・苔。屋根面は細かく分割して、わずかな凹凸を付ける |
| 軒先・木組み | 軒先は厚い切り口が見えるようにする。妻面は柱と貫の格子に障子窓（階ごとの段）。1 階は板壁と障子、石の土台 |
| 家ごとの違い | 大きさ・窓の段数・入口の位置・下屋（農具を置く小さな板屋根の小屋）・周りの道具で変える |
| 屋根の状態 | 「ふつうの古さ」「傷み（色が暗く苔が多い、へこみ）」「一部だけ新しい」「新しい（明るい黄金色）」を頂点色の切り替えで表す（形は変えない） |

### サエ家の向き（配置の変更）

物語では「サエ家の屋根の**南面**を葺き替える」。これまでのサエ家は棟が南北に通っていて、南側は妻面（屋根の面がない）だった。
**サエ家を 90° 回し、南に屋根の面が向くようにする。** 入口は南の長い辺に移す。ミネ家・伊助家はもともと南北に屋根の面が向いているので、物語の「北面」「南面」と見た目が一致する。

- 広場と橋から、傷んだ南面がよく見える。葺き替えの前後の違いもここで分かる。
- 傷みのひどい所は、南面の西側（「サエ家の屋根」を調べる場所の上）に置く。手持ちの茅で一部だけ葺いた場合は、そこだけ新しくなる。
- 回したことで建物の足元が東西に長くなる。軒下の薪・当日の村の人たちの位置を動かし、結帳の文箱を縁先へ寄せる。

### 見分けやすさ

- **サエ家**：村の中央で最も大きい。南面の傷み（→当日の足場→葺き替え後）が目印。縁側と文箱。
- **伊助家**：東。下屋に農具、軒下に稲束、隣にはさ掛けと畑。
- **ミネ家**：西。茅置場と、壁に立てかけた茅の束。
- 宗平の作業場：北。板屋根の作業小屋、梯子・材木・縄。

## 2. 村の環境

- 空：地平線から天頂への色の移り変わり（簡単なシェーダー）。霧の色を地平線に合わせる。
- 遠景の山：輪郭の異なる尾根を 3 層、遠いほど霧の色に近づける。
- 田んぼ：水路の南に、刈り取りの終わった田（切り株の色）と畦、はさ掛け。
- 水路：両岸の石積み。橋のたもとの石。
- 草むら・低木：道と調べられる物の周りを避けて、背の低いものだけを散らす（当たり判定なし）。
- 生活の道具：桶、背負い籠、薪、茅の束、立てかけた農具。家の壁際か当たり判定の内側に置き、道をふさがない。
- 背景の家：村の外れに小さめの合掌造りを足して、村の広がりを出す（歩ける範囲の端）。

## 3. 人物

| 人物 | 見分ける手がかり（色・シルエット） | 待機の動き |
|---|---|---|
| 主人公 | 藍の上着、笠、肩掛けの袋（手帳） | 歩行・走行、止まると揃える |
| トキ | 青緑、小柄、白い鉢巻とたすき | 体重を左右に移す、きょろきょろする |
| サエ | 赤茶の着物、紺の前掛け、白い手ぬぐい | 手を前で重ねる。第3幕は杖をつく（少し体重をかける程度） |
| 伊助 | 幅広の麦わら帽子、背負い籠、脚絆 | 畑の方を気にする、帽子のつばに手をやる |
| 宗平 | 白髪とひげ、がっしりした体格、膝まである墨色の上着 | 腕を組む、ゆっくりうなずく |
| ミネ | 葡萄色、茶の手ぬぐいと前掛け、帳面を持つ | 帳面を胸元に持つ |
| 村の人たち | くすんだ色、かぶり物いろいろ | 役割ごとの作業の動き |

- 会話中：相手の方を向き、話している間は手振りとうなずき。
- 人物のモデルは部位（胴・頭・腕・脚）ごとに頂点色で一つにまとめ、全員で一つのマテリアルを使う（描画呼び出しを減らす）。

## 4. 屋根葺き当日

当日の見た目は、決めた計画の結果（`OUTCOMES[id]`）だけから決まる（`roofDayStage()`）。

| 要素 | 計画との対応 |
|---|---|
| 足場の範囲・屋根の上の人数 | ミネの茅で南面すべて → 南面いっぱいに足場、屋根の上に 3 人／手持ちの茅で一部 → 傷んだ所だけ足場、2 人 |
| 茅の山 | ミネの茅 → 新しい茅の大きな山（ミネが運び込んだ）／手持ち → 小さな山 |
| 宗平 | 全計画で段取り（屋根を指して指示する） |
| 伊助 | 延ばした計画だけ当日に来る（茅を担ぐ）。来ない計画では畑にいる（Phase 4 と同じ） |
| ミネ | 茅を借り、延ばさない計画だけ当日に来る（茅の山のそば）。延ばした計画では茅場（Phase 4 と同じ） |
| 名前のない村の人たち | 茅を運ぶ（歩いて往復）、梯子で受け渡す、屋根の上で葺く |

- 名前のある住民の立ち位置・会話は Phase 4 の `placements` のまま。**参加していない住民は当日の作業の場に出さない**（テストで確認）。
- 茅を運ぶ人は短い往復を歩く。プレイヤーが近くにいるときは立ち止まり、通り抜けや押し出しが起きないようにする（動く当たり判定）。

## 5. 光と描画性能

- 秋の午後の光：日差しをやや暖かく低めに、空の光を青く、地面からの照り返しを暖かく。影の範囲は村全体（固定）。
- 計測：`npm run shots`（GPU）で場面ごとの描画呼び出し数・三角形数・FPS を記録し、変更前と比べる。
- 目安：変更前から描画呼び出し数を大きく増やさない（当日でも 350 以下）。動かない物は結合、木・草は InstancedMesh、人物は部位ごとに一つのメッシュ。

## 6. 完了条件（PHASE_PLAN §9 ＋ユーザー指示）

- 重要な建物（サエ家・伊助家）が遠くからでも区別できる
- 合掌造りの特徴（急勾配の厚い茅葺き、軒先、妻面の窓、木組み）が表現されている
- 屋根の状態（傷み・一部・葺き替え後）が見て分かる
- NPC 5 人と主人公を色とシルエットで見分けられる。全員が同じ棒立ちに見えない
- 屋根葺き当日の人物と役割が、計画の結果と一致する
- 村全体のアートスタイルが統一されている
- 探索・会話・調査・当たり判定・セーブ・全エンディングが壊れていない
- 描画性能に著しい悪化がない

### 7.2 外部素材とライセンス

**外部の 3D モデル・テクスチャ・画像・フォントは使っていない。** 建物・人物・地形・空はすべて Three.js の基本形状とコードで生成するジオメトリ、テクスチャは実行時に Canvas へ描いて作る（プロジェクト内のコード）。

| 素材 | 配布元 | 利用条件 | 改変 | クレジット |
|---|---|---|---|---|
| 茅の繊維・切り口・板・障子・地面のテクスチャ | このプロジェクトのコード（`src/render/textures.ts`） | — | — | 不要 |
| 建物・人物・地形・空・山並みの形 | このプロジェクトのコード | — | — | 不要 |
| three.js（描画ライブラリ、既存） | npm `three` | MIT License | なし | ライセンス表記の同梱が必要（Phase 9 の提出資料で対応） |

新しい npm 依存は追加していない。

### 7.3 史実と創作について

- 表現したのは急勾配の茅葺きの切妻、厚い軒先、妻面の階ごとの窓、木の躯体と障子、石の土台、はさ掛け・水路・田畑。
- 入口の上の小さな板屋根、縁側、農具小屋、桶・背負い籠などは、日本の農村の家に一般的な形として置いたもので、白川郷に固有の特徴として示してはいない（解説画面にも書いていない）。
- サエ家の向きは、物語の「南面」と見た目を合わせるために決めた（実際の集落の家の向きを再現したものではない）。
- 服装は時代を特定しない素朴な野良着の形。

### 7.4 描画負荷（Intel Iris Xe、ヘッドレス Chrome・D3D11、1280×720、垂直同期なし）

`npm run shots`（`GPU=1`）で、同じ視点・同じ場面を Phase 4 の版と比べた。

| 場面 | 描画呼び出し（前→後） | 三角形（前→後） | FPS（前→後） |
|---|---|---|---|
| 第1幕（11 視点） | 131〜190 → 158〜225 | 13.0万〜13.5万 → 21.9万〜23.5万 | 330〜409 → 261〜313 |
| 屋根葺きの日（4 計画×3 視点） | 206〜318 → 258〜421 | 13.7万〜14.2万 → 23.9万〜26.6万 | 313〜336 → 240〜282 |
| 第3幕・結末 | 134〜181 → 168〜219 | 13.0万〜13.4万 → 22.1万〜23.3万 | 315〜369 → 246〜295 |

- 60fps に対して 4 倍前後の余裕がある。ソフトウェア描画（SwiftShader）の自動テストでの値は性能を表さない。
- 主な工夫：動かない物は材質ごとに結合（足場・梯子・茅の山も当日に組んだ後で結合）、木・草・岸の石は InstancedMesh、人物は部位ごとに一つのメッシュ（一人 8 回）と共有マテリアル。屋根葺きの日の足場を結合する前は、描画呼び出しが最大 506 だった。
