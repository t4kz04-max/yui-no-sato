| 要素 | 試作の状態 | 対応 |
|---|---|---|

### 技術的な判断

1. **全面破棄ではなく「移植＋再構成」**：見た目の構築コードは移植し、設計書 N 節で再設計対象とされた移動・当たり判定・カメラ・構造を作り直した。
2. **当たり判定は XZ 平面の 2D（回転矩形＋円）**：ジャンプのない探索ゲームのため 3D 物理エンジンは不要。描画と同じ配置データ（`world/layout.ts`）から生成し、見た目と判定のずれを防ぐ。
3. **状態と描画の分離**：`PlayerController`（純粋ロジック）→ `PlayerView`（見た目に反映するだけ）。カメラも `orbit.ts`（純粋計算）と `ThirdPersonCamera`（Three.js）に分離。
4. **移動はフレームレート非依存**：加速を解析的に積分し、30fps と 144fps で移動距離が一致する。dt は最大 0.1 秒に制限。
5. **視点操作はマウスドラッグ方式**：ポインターロックは会話・手帳 UI のクリック操作と衝突しやすいため見送り。
6. **描画負荷の削減（計測に基づく）**：初版の約 1,170 回の描画呼び出しを、木の InstancedMesh 化と静的メッシュの結合で約 96 回に削減。
7. **影は村全体を覆う固定範囲**（2048px）。
8. **Tailwind は不採用**。
9. **入力の抽象化**：ゲームはキーコードを直接見ず `MoveIntent`／`OrbitInput` を受け取る。
10. **座標系**：北 = -Z、南 = +Z、東 = +X、西 = -X。スタートは橋の南（0, 31）で北を向く。
11. **村の配置は仮**：主要地点を歩いて一周約 1 分。
