## 3. ミネ：茅を提供する条件と、できない事情

| 項目 | 内容 | 根拠 |
|---|---|---|
| 持っているもの | 茅の蓄え。ただし来年は自分の家でも使う | 設計書 D |
| 貸す条件 | **いつ・どう返すかがはっきりしていて、記録に残すこと**。返しは**茅で**（来年の秋、同じ束数） | 設計書 D・G（返却の約束を明確に、貸借を記録する必要性） |
| 貸せない事情 | 手伝いで返すと言われても困る（要るのは茅）／口約束では困る（以前、行き違いがあった🔶）／延ばして傷みが広がると、もっと要る量は今の蓄えでは足りない | 設計書 D、Phase 2 の暫定設定（ミネの控え） |
| 宗平の代わり | 茅刈りの段取りなら引き受けられる。**茅刈りを仕切るなら新しい茅の当てがつくので、延ばした場合でも茅を貸せる** 🔶 | 設計書 H（P2）を、茅の事情でつないだ本書の暫定設定 |
| 知る場所 | ミネと話す（条件）→ 許可を得て控えを読む（記録の必要）→ 宗平の別件を知った後に聞く（代われること・茅の当て） | 第1幕の会話・調査 |

## 4. 作業台の項目（第1幕）と、選べるようになる条件

| 項目 | 選択肢 | 選べる条件（知っている情報） |
|---|---|---|
| 日取り | 予定日のまま／刈り入れの後に延ばす | 延ばす：伊助の事情（刈り入れと重なる） |
| 伊助への頼み方 | 頼まない／当日の手伝い／前日の準備 | 前日：伊助と詳しく話す |
| サエ家からの申し出 | なし／伊助家の刈り入れに人を出す | 刈り入れを手伝う：畑を二度見る |
| 茅 | ミネ家から借りる／サエ家の手持ちだけで葺く | 手持ち：サエ家の茅置き場を調べる 🔶（手持ちでは一部しか葺けない） |
| ミネへの返し方（茅を借りるときだけ表示） | 手伝いで返す／来年の秋に茅で返す／来年の秋に茅で返すと結帳に記す | 茅で返す：ミネの条件を聞く／結帳に記す：ミネの控えを読む |
| 宗平の別件（延ばすときだけ表示） | そのまま／茅刈りの段取りをミネに頼む | 宗平の別件を知る |

- 表示する項目は案に応じて絞る（茅を借りないなら返し方を出さない等）。
- 最初に広げる案：予定日／伊助に当日／申し出なし／ミネから借りる／手伝いで返す（サエと主人公が最初に思いつく素朴な案）。

## 5. 返事の規則と、サエ・伊助の事情との衝突

返事は**今の事情と提案内容だけ**で決まる（過去の貸し借り・好感度は入力にしない）。

| 住民 | 断る・条件付き | 承諾 |
|---|---|---|
| サエ | 延ばすのに伊助が当日来ない → 断る | 他はすべて承諾（手持ちの茅なら「全部は葺けない」、延ばすなら「傷みが心配」、伊助に頼むなら「負担が気がかり」と一言） |
| 伊助 | 予定日に当日 → 断る／予定日に前日・申し出なし → 条件付き | 前日＋刈り入れの手伝い／刈り入れの後に当日 |
| 宗平 | 延ばすのにミネが茅刈りを代わらない → 断る | 予定日（人手・前日準備・茅の量に応じた一言）／延ばしてミネが代わる |
| ミネ（茅を借りる・宗平を代わるときだけ） | 手伝いで返す → 条件付き／茅で返すが記さない → 条件付き／延ばすのに茅だけ借りる → 断る | 茅で返し記す（予定日）／延ばして茅刈りを代わり茅も貸す／茅刈りを代わるだけ |

**衝突の構造**
- サエ（予定どおり・傷みが心配）× 伊助（刈り入れ）：予定日なら伊助は当日来られない。
- 伊助を当日加えたい（延ばす）× 宗平（茅刈り）：ミネに代わってもらう必要。
- 延ばす × 茅：傷みが広がると茅が余計に要る。ミネが茅刈りを仕切れば当てがつくが、ミネの負担が大きくなる。
- ミネから借りない × 屋根：手持ちでは一部しか葺けない（残りは持ち越し）。

## 6. 成立する計画と結果（第1幕）

全員の承諾が得られる組み合わせは 8 通り。結果は項目ごとの部品から組み立てる。

| 計画（設計書） | 組み合わせ | 実現すること | 残る負担・約束 |
|---|---|---|---|
| P1 予定日を優先 | 予定日・伊助に頼まない・ミネの茅（記す） | 予定日に全面を葺く。宗平が段取り | 人手が少なく二日がかり。伊助は加わらない。サエ家→ミネ家「来年の秋に茅で返す」 |
| P1'（手持ち） | 予定日・頼まない・手持ちの茅 | 予定日に、傷みのひどい所だけ葺く。借りが増えない | 残りは持ち越し。二日がかり |
| P3 前日準備を分担 | 予定日・前日＋刈り入れの手伝い・ミネの茅（記す） | 一日で全面。伊助も前日に加わる | 伊助の刈り入れが半日止まる。サエ家に刈り入れの手伝いの約束とミネへの茅の返し |
| P3'（手持ち） | 予定日・前日＋手伝い・手持ち | 一日で一部。伊助も加わる | 残りは持ち越し。刈り入れの手伝いの約束 |
| P2 日程を変更 | 延ばす・伊助に当日・宗平の茅刈りをミネが代わる・ミネの茅（記す） | 全員がそろって全面を葺く | 待つあいだに傷みが広がる。ミネが茅刈りを仕切り茅も貸す（大きな負担）。宗平はミネに借り。サエ家はミネに茅の返し、伊助に返し |
| P2'（手持ち） | 延ばす・当日・ミネが代わる・手持ち | 全員がそろう。ミネから茅は借りない | 傷みが広がったうえに一部だけ。ミネは茅刈りの負担 |
| P2＋手伝い | 上の2つに「刈り入れを手伝う」 | 刈り入れが早く済み、待つ期間が短い | サエ家が待つあいだに人を出す |

**どれも正解ではない：** 早さ・屋根の範囲・誰が加わるか・誰に何が残るか・ミネと宗平の負担が互いに引き換え。

**成立しない組み合わせ：** 予定日に伊助に当日／前日だけで申し出なし／延ばすのに伊助が当日来ない／延ばすのに宗平の別件をそのまま／ミネに手伝いで返す・口約束／延ばして茅だけ借りる。いずれも相談で理由が分かり、見直しの手がかりになる。

## 7. 屋根葺き当日（roofDay）

- 計画に応じて、サエ家の前に集まる人が変わる（宗平は段取り、延ばした場合は伊助も、茅を借りた場合はミネが茅を運び込む）。村の人たち（名前のない人物）が手伝いに来ている。
- 参加しなかった人にも会える（伊助は畑、茅刈りを代わったミネは茅場の段取りで不在 等）。
- サエと話して「一日を終える」と結果画面へ。

## 8. 第3幕「返す日」（三年後🔶）と Q1〜Q3・E1〜E3

**状況（暫定設定🔶）：** 三年後の秋、今度は伊助家が屋根を葺き替える。結帳には十五年前の「伊助家→サエ家（返しはまだ）」と、第1幕の記録が残っている。**サエは夏に足を痛め、屋根の上の仕事はできない**（下の仕事ならできる）。これは設計書 J「過去の記録に協力が残っていても、現在の状況では予定どおりに実行できない場合がある」を具体化した暫定設定。

| 選択（設計書 J） | 作業台の案 | 返事 | 結末 |
|---|---|---|---|
| Q1 事情を確認し、役割を相談し直す | サエ家に「下の仕事」を頼む（サエの足のことを知ると選べる） | サエ・伊助とも承諾 | **E1 つながる約束** |
| Q2 当初の約束どおりに協力を提案する | サエ家に「記録どおり屋根の上の仕事」を頼む | サエは断る（足のこと）→ 強制できない | 見直し（Q1／Q3）か、サエ抜きで葺く |
| — | サエ家には頼まず、村の手で葺く | 伊助は承諾 | **E2 屋根は完成したけれど**（返しは残る） |
| Q3 無理な約束はせず、相談を続ける | 今年は見送る | 伊助は承諾（屋根はもう一年もつ） | **E3 もう一度、相談しよう** |

- 第1幕の結果は、第3幕の台詞・結帳・エンディングの文章に反映する（例：P3 の刈り入れの手伝いを果たしたこと、P1' で残ったサエ家の屋根の持ち越し、ミネへの茅の返し）。
- **記録を理由に参加を強制できない**（Q2 は必ずサエの返事で止まる）。返事は第1幕の結果に関係なく、今の提案内容で決まる。
- エンディング画面：結末の文章、自分の選択（第1幕・第3幕）、協力の関係、結帳の変化。どれも点数ではなく具体的な出来事で示す。E3 は失敗として描かない（設計書 K）。

## 9. 史実と創作の区別

- ゲーム内の解説画面（ポーズ画面・エンディングから開ける）に、設計書 B 節の「史実に基づく要素」「ゲーム用の創作」を並べる。

- 本書の🔶（宗平の茅刈り、ミネの茅の当て、サエの足、三年後）はすべて創作として扱い、史実の説明に使わない。

## 10. 保存と移行

- 保存形式 版3：章（chapter）、計画を章ごとに保存（第1幕の計画・第3幕の計画）。
- 版2（Phase 3 の計画あり）→ 版3：探索の記録（フラグ・情報・意向）は残す。旧計画は項目が足りず新しい規則で検証できないため破棄し、旧計画の結果として入った状態（屋根の葺き替え・約束・伊助の意向の変化）を取り除いて第1幕に戻す。読込時に知らせる。
- 版1 → 版3：計画なしとして読み込む。

## 11. 進行不能・矛盾の検討

| 可能性 | 対策 |
|---|---|
| 第1幕でどの計画も成立しない | 「予定日・頼まない・手持ち」は情報なしでも選べ、全員が承諾する（宗平・サエ）。茅を借りる場合もミネの条件は会話と控えで必ず知れる |
| 手持ちの茅の選択肢が見つからない | 最初の案（ミネから借りる・手伝いで返す）はミネが条件付き → 相談で理由が分かり、ミネの条件を聞きに行ける。サエ家の茅置き場は家の横にあり、トキ・サエが案内する |
| 第3幕で決められない | 「今年は見送る」「サエ家には頼まない」は常に選べ、伊助が承諾する |
| 章をまたいで古い承諾が使われる | 計画は章ごとに別に保存。返事は案ごとに記録し、決定は今の案への返事だけで判定 |
| 屋根葺き当日に会話が途切れる | 当日の入口を各住民に用意。サエと話せば必ず一日を終えられる |
| セーブの互換 | §10 の移行。移行できない記録は破損として退避（Phase 2 の仕組み） |
