# 縦切り試作（Phase 3）設計：サエ家の屋根と伊助家の刈り入れ

**目的：** 探索 → 事情の理解 → 計画 → 相談 → 計画の見直し → 結果 を、短いプレイで一本の流れとして体験できるようにする（PHASE_PLAN §7）。
**題材（ユーザー決定）：** サエ家の屋根の修繕と、伊助家の刈り入れの日程の衝突。中心人物はサエと伊助。
**状態の詳細：** `docs/STATE_TABLE.md`（本書と対応させて更新）。

凡例：🔶 ゲーム用の暫定設定（ユーザー指定または本書で仮に決めたもの）

## 1. 計画 P1〜P3 の意味と条件（縦切り試作版）

計画は「項目ごとの選択」の組み合わせで作る。P1〜P3 は代表的な組み合わせの名前であり、プレイヤーには項目を選ばせる（名前付きの正解を選ばせない）。

| 計画 | 組み合わせ | 必要な承諾 | 得るもの | 失うもの・残るもの |
|---|---|---|---|---|
| **P1 予定日・伊助に頼まない** | 予定日／頼まない／申し出なし | サエ | 予定どおり完成。伊助に負担をかけない。新しい貸し借りが増えない | 人手が少なく二日がかり。伊助は関わらない。十二年前の返しはそのまま |
| **P3 前日準備を分担** | 予定日／前日の準備／刈り入れを手伝う | サエ・伊助 | 予定どおり一日で完成。伊助も関われる | 伊助の刈り入れが半日遅れる。サエ家に「刈り入れを手伝う」約束が残る（十二年前の返しも残ったまま） |
| **P2 刈り入れの後に延ばす** | 刈り入れの後／当日の手伝い／（申し出は任意） | サエ・伊助 | 伊助も当日加わり、人手がそろう | 待つ間に屋根の傷みが進み、葺き替えの手間が増える。伊助への新しい返しが残る |
| P2' 延ばす＋刈り入れを手伝う | 刈り入れの後／当日／刈り入れを手伝う | サエ・伊助 | 刈り入れが早く済み、待つ期間が短くなる。伊助への手伝いはその場で果たされる | サエ家は自分の屋根を待ちながら他家の刈り入れに人を出す。傷みは少し進む |

**正解を一つにしない理由：** 早さ（P1・P3）、伊助が関われること（P3・P2）、新しい負担を増やさないこと（P1）、屋根の傷み（P2 が不利）、約束が残ること（P3）が互いに引き換えになっている。すべての情報を集めても、何を優先するかはプレイヤーが決める。

## 2. プレイヤーが変更できる項目（宗平の作業台）

| 項目 | 選択肢 | 選べるようになる条件（知っている情報） |
|---|---|---|
| 日取り | 予定日のまま | 常に |
| 〃 | 刈り入れの後に延ばす | 伊助の当日の都合 ≧「刈り入れと重なる」 |
| 伊助への頼み方 | 頼まない／当日の手伝いを頼む | 常に |
| 〃 | 前日の準備を頼む | 伊助の当日の都合 ≧「前日の半日なら抜けられるかもしれない」 |
| サエ家からの申し出 | なし | 常に |
| 〃 | 伊助家の刈り入れを手伝う | 伊助の畑 ≧「刈り入れはあと十日ほど。人手があれば早く済む」 |

- 未取得の情報を前提とした選択肢は出さない（PHASE_PLAN §8 の条件を先取りして守る）。隠れている選択肢があるときは「まだ考えられる案があるかもしれない」とだけ示す。
- 「頼まない」のに「刈り入れを手伝う」は組み合わせられない（伊助の承諾が必要な約束になるため。画面で理由を示す）。
- 作業台は、サエから日取りの話を聞いた後に使える。
- 案を変えると、関係する人にもう一度相談する必要がある（以前の案への返事は、その案に対してだけ有効）。

## 3. 住民の反応が変わる条件

返事は**今の事情と提案内容だけ**で決まる。過去の貸し借り（結帳）、会話の回数、好感度では決まらない。同じ案には同じ返事をする。

### 伊助

| 案 | 返事 | 理由（台詞の要旨） |
|---|---|---|
| 予定日＋当日 | 断る | 刈り入れと重なる（理由を知らないプレイヤーには「無理だと言ったろう」とだけ言う） |
| 予定日＋前日、申し出なし | 条件付き | 前日の半日でも刈り入れは遅れる。その分をどうするか次第 |
| 予定日＋前日＋刈り入れを手伝う | 承諾 | 遅れを取り戻せるなら前日の半日は出る |
| 刈り入れの後＋当日（申し出の有無） | 承諾 | 刈り入れの後なら当日から出られる |
| 刈り入れの後＋前日 | 承諾 | 前日だけでいいなら（ただしサエが断る） |
| 頼まない（申し出なし） | 相談不要 | — |

- 相談中に「結帳の記録を持ち出して頼む」こともできる（結帳を読んだ後）。伊助は「昔のことで今年の刈り入れは待ってくれん」と答え、返事は変わらない（**過去の協力と現在の同意は別**）。

### サエ（家主として、すべての案に返事をする）

| 案 | 返事 | 理由 |
|---|---|---|
| 予定日＋伊助に頼まない | 承諾 | 伊助さんに無理を言わずに済む。人手は少ないがなんとかする |
| 伊助に頼む（申し出なし）で、他は成立する案 | 承諾（気がかりを残す） | また伊助さんに頼ることになる。十二年前の分も返せていないのに |
| 伊助に頼む＋刈り入れを手伝う | 承諾 | 頼むだけでは気が引ける。うちも楽ではないが人を出す |
| 刈り入れの後に延ばす＋伊助が当日来ない | 断る | 来られないのに延ばせば、その間にも屋根は傷む |
| 刈り入れの後に延ばす＋伊助が当日 | 承諾（傷みの心配を残す） | 延ばせば傷みは進む。それでも伊助さんが来られるなら |

- サエの返事にある気がかり（負担・傷み）は、相談の中で「サエが日取りを動かしたくない理由」として手帳に記録される（別の経路：屋根を調べた後に話す／結帳を読んだ後に話す）。

## 4. 結果（成立するもの・しないもの）

**決定できる条件：** 案に関係する全員が、その案に「承諾」していること。承諾していない住民の協力を前提にした計画は決められない（設計書 A：同意なしに協力を強制できない）。

| 結果 | 案 | その後の状態 |
|---|---|---|
| **R1 少ない人手で、予定どおり** | P1 | 屋根は葺き替え済み（二日がかり）。結帳：村の人たち→サエ家。伊助との新しい貸し借りなし。十二年前の返しは「まだ」のまま |
| **R2 前日準備を分け合って** | P3 | 屋根は一日で葺き替え。結帳：伊助家→サエ家 前日の半日（返しはまだ）。約束：サエ家→伊助家「刈り入れの手伝い」 |
| **R3 刈り入れを待って** | P2 | 十日後に葺き替え。待つ間に傷みが広がり手間が増えた。結帳：伊助家→サエ家 当日の手伝い（返しはまだ）。伊助の意向：当日の手伝い＝承諾（延ばした日程で） |
| **R3' 刈り入れを手伝い、待って** | P2' | 七日後に葺き替え。結帳：サエ家→伊助家 刈り入れの手伝い（済）＋伊助家→サエ家 当日の手伝い |

**成立しない案**（決定ボタンが押せない。相談で理由が分かる）：予定日＋伊助に当日を頼む／予定日＋前日（申し出なし）／延ばす＋伊助が当日来ない。

結果画面では点数を出さず、「屋根」「伊助」「サエ」「結帳に記されたこと」「残った約束」を具体的に示す。プレイヤーが知っていた情報によって結果の文章も変わる（例：伊助の事情を知らないまま R1 にすると「伊助さんがなぜ断ったのか、結局聞けずじまいだった」）。

結果の後は村に戻り、サエ・伊助・トキの台詞、結帳、手帳の約束、サエ家の屋根の見た目が結果に応じて変わる。

## 5. 状態遷移

### 5.1 計画の状態（`planPhase`）

```
none ──(作業台で案を作る)──▶ pending ──(関係者に相談)──┬─▶ ready（全員承諾）──(作業台で決定)──▶ decided
  ▲                         ▲                         │
  │                         └──(案を変える)◀──────────┴─▶ revise（断り・条件付きがある）
  └─────────────── 案を変えると、その案についての相談は最初から（以前の返事は履歴として残る）
```

- `pending`：関係者の中にまだ相談していない人がいる（断り・条件付きはない）
- `revise`：今の案に、断り・条件付きの返事がある → 案を見直す理由
- `ready`：関係者全員が今の案を承諾
- `decided`：決定済み。以後は案を変えられない（記録として残る）

### 5.2 情報（トピック）の追加・変更

|---|---|---|---|
| `sae.dateReason` | `hesitant` 未 | サエに「日取りは動かせないか」 | — |
| 〃 | `roofWorry` 分 🔶 | 屋根を調べた後サエと話す／延ばす案を相談する | — |
| 〃 | `burden` 分 🔶 | 十二年前の手伝いを知った後サエと話す／伊助に頼む案を相談する | — |

### 5.3 住民の意向（既存）への反映

決定時だけ、結果に応じて記録する（例：R3 で伊助の「当日の手伝い」が 断っている → 承諾（延ばした日程で））。相談の返事そのものは「計画への返事」として案ごとに別に持つ。

## 6. 情報を知らなくても進める経路

- サエと話すだけで作業台を使え、「予定日・伊助に頼まない」（R1）で決定できる。進行不能にはならない。
- その場合、結果の文章で「知らないまま決めたこと」が示される（探索の意味を失わせない）。
- 伊助の事情を知らずに「当日の手伝い」を頼むと断られ、理由も教えてもらえない → 畑を見る理由が生まれる。

## 7. 進行不能・矛盾の可能性と対策

| 可能性 | 対策 |
|---|---|
| どの案も決定できない | 「予定日・頼まない」は常に選べ、サエは必ず承諾する（テストで確認） |
| 案を変えた後に古い承諾で決定できてしまう | 返事は案ごとに記録し、決定は今の案への返事だけで判定する |
| 承諾していない住民が承諾済み扱いになる | 決定時に関係者全員の承諾を検査（StoryState とテスト） |
| 未取得の情報を前提とした案が出る | 作業台の選択肢は情報の条件で表示を制御。セーブデータ読込時も不正な案は除外 |
| 会話の中断で返事が半端に残る | 返事は「相談する」を選んだ瞬間に確定。中断しても取り消さないが、未相談の人は未相談のまま |
| セーブ・ロードで計画が崩れる | 案・返事・決定を保存。読込時に、返事が規則と食い違う・決定の条件を満たさない記録は除外または破損扱い |
| 決定後に案を変える | 決定後は作業台が閲覧専用 |
| 結果の後に会話が以前の内容に戻る | 結果の後の入口を最優先にする |
