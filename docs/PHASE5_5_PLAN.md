## 2. サエ家の室内（ゲーム用の創作建築）

- サエ家は架空の家で、実在の家屋の復元ではない。間取りは資料の一般的な構成（入口の土間 → 囲炉裏のある板の間 → 奥の部屋）に沿わせる。
- 外観（Phase 5 で 90° 回した向き、南面の傷み）は変えない。家の外形はそのままで、壁を中空にして中に室内を作る。
- 範囲は 1 階だけ。南の入口 → 土間（板の間との境に上がり框）→ 中央の板の間と囲炉裏・火天 → 北の壁際に結帳の棚。東は閉じた襖（奥の部屋、入れない）、西は薪・道具の置き場と屋根裏への急な階段（飾り）。居間の上は格子の天井。
- 明かり：囲炉裏の火の暖かい光と、障子からの外の明るさ。屋外では室内の明かりを消す。

## 3. 出入りの仕組み

- 入口は南の長い辺の中央。入口に近づいて **E**：許しがあれば家に入る（屋内へ移る）。許しがなければ「サエさんに断ってから」と出て入れない。
- 許し：サエに「結帳を見せてもらえますか？」と頼むと得られる（既存のフラグ `asked:saeLedger`）。**すでに結帳を読んだことがある記録（Phase 5 以前の保存）も許しがあるものとみなす。** 一度得たら以後は自由に出入りできる。
- 頼む選択肢は、第1幕・屋根葺きの日・第3幕・結末のサエとの会話すべてに出す（結帳を読んでいない・頼んでいない間だけ）→ どの章でも入れなくなって詰まることはない。
- 室内の入口で **E** を押すと外に出る。出入りは短い暗転で切り替える。
- 室内では、当たり判定・カメラの遮蔽物・調べられる物を室内のものに切り替える。カメラは室内用の距離（近め）と角度にする。

## 4. 結帳の移設と進行条件

- 縁先の文箱を、室内の北の壁際の棚へ移す。結帳のデータ・画面・解放条件・章ごとの中身は変えない。
- 変わるのは「結帳を読むにはサエに頼んで家に入る」ことだけ。目的表示に「サエに、結帳を見せてもらえるか頼む」を足し、トキの案内の台詞を室内に合わせる。
- 保存：会話のたびに自動で記録するので、室内で記録されることがある。読み込んだ位置が室内なら室内として再開する。章が進むとき（屋根葺きの日・三年後）は屋外の決まった場所に置き直す。

## 5. 橋の柵の当たり判定

- 原因（調査）：橋の通行を止める判定は「水路の箱」だけで、橋の両脇は水路の幅（z 20.9〜25.1）しか塞いでいない。欄干は z 20.1〜25.9 まであるので、橋の両端の約 0.8m ずつ（地面と橋が接する所）は欄干があるのに横へ抜けられる。
- 修正：左右の欄干それぞれに、欄干の全長に沿った細い箱の判定を足す（橋の通路側の幅は変えない）。橋のたもとの石にも判定を足す。入口・出口（橋の両端）は開けておく。
- 確認：単体テスト（左右の柵の中央・両端・地面との境で通り抜けられない、入口・出口・中央は通れる）と、ブラウザで実際に歩かせる確認。

### 6.3 橋の欄干の当たり判定

- 原因（確認済み）：修正前の判定で橋の端（z=20.2、25.8）から横へ歩かせると、欄干を抜けて x=12m 先まで歩けた。橋の中央（z=23）では水路の判定で止まっていた（x=1.05）。
- 修正後：欄干の全長に沿った判定で、両端・中央・地面と接する所のどこでも、欄干の内側（x=±1.03）で止まる。通路の幅は変えていない（端寄り x=±0.95 を歩いても引っかからない）。

- 室内は屋内にいるときだけ表示し、結合して描く（屋外の描画呼び出しは +4 程度）。
- 屋外で 5〜10% 下がった（測るたびの揺れも同じくらいある）。主な理由は、囲炉裏の明かり（PointLight）を常に置いていること（強さ 0 でも計算される）と考えられる（切り分けはしていない）。明かりの表示を切り替えるとシェーダーを作り直して一瞬止まるので、強さだけを切り替える方式にした。室内の空の光は、屋外と共用の光を強めて足している（明かりを増やさない）。
