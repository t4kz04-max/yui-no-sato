# Phase 6.5 作業計画：視認性・空間整合性・キャラクター品質の改善

位置づけ：PHASE_PLAN の正式な Phase ではなく、Phase 6（Beta）の手動確認を受けた改善（ユーザー指示 2026-10-15）。
物語・分岐・返事の規則・セーブの形式は変えない。

## 1. 現状の確認（実装前）

比較用の撮影：`node scripts/compare-shots.mjs before` → `test-results/compare/before-*.png`

| 項目 | 現状（Phase 6） | 原因 |
|---|---|---|
| 屋根を見上げる | 上下角の下限が 0.05（ほぼ水平）。カメラを下げても注視点（主人公の頭上）より上を向けない | `DEFAULT_ORBIT_LIMITS.minPitch`。カメラは常に注視点を見る |
| 屋根を調べる | 調べている間も通常の追従カメラのまま。屋根の上部・傷みが画面の外 | 調査対象に合わせた構図がない |
| 屋根の傷み | 黒ずみ・苔・浅いへこみ（0.3〜0.55m）だけ。遠目には影と区別しにくい | 形の乱れ（茅の飛び出し・欠け）がない |
| 作業場 | 正面が開いているのに、建物全体が一つの箱の当たり判定で入れない | `buildingCollider` が外形の箱 |
| 人物 | 円柱と球の組み合わせ。膝がなく、袖・襟・帯・裾の重なりがない。表情が動かない | Phase 5 の部位ごとのメッシュ（1 人 8 回の描画） |
| 軒下 | 屋根の影の中で板壁と柱が暗く、木組みが読み取りにくい | 空の光の地面側（照り返し）が暗い |

## 2. 方針と実装

### 2.1 カメラ（最優先）
- 三人称のまま、上下角の下限を負（見上げ）まで広げる。見上げるときは、カメラを地面の少し上に保ったまま視線だけを上へ傾ける（地面・建物へのめり込みは従来の判定を使う）。
- 調べる対象に「観察の構図」を持たせる（データ：位置と注視点）。サエ家の屋根を調べている間は、広場から屋根の傷んだ所を見上げる構図へ滑らかに移り、終わると戻る。
- 室内・会話・橋・作業場のカメラは変えない（見上げの下限は屋外だけ）。

### 2.2 屋根の傷み
- 傷んだ所のへこみを深くし、まだらに欠けた所（下地の暗い色が見える）を加える。
- 傷んだ所の茅が乱れて飛び出している様子（細い茅の房）を、傷みの範囲だけに置く。屋根の状態が old のときだけ表示し、葺き替え後・三年後には出さない（既存の状態の切り替えを使う）。
- 葺き替え・作業の進み具合・三年後の見た目の仕様は変えない。

### 2.3 宗平の作業場
- 自由に歩いて入れる方式にする（建物の外形の箱をやめ、壁・柱・中の物ごとの判定にする）。正面の開口（幅 4.8m）から入り、同じ所から出る。
- 床は土台の上（地面より少し高い）。作業場の中ではカメラを近め・低めにし、壁際では回り込む（サエ家の室内と同じ仕組み）。屋根はカメラの遮蔽物にする。
- 中の物：材木の束、作業台（鉋・のみ・墨壺）、作りかけの梯子、縄の束、茅を束ねる道具、木屑。新しい物語・調べる物は足さない。
- 比較した案：開口を柵・材料で塞ぐ方式（実装は簡単だが、開いた正面と中の作業台が「見えるのに入れない」印象は残る）。今回は入れる方式を採る。

### 2.4 人物（主人公＋5 人、村の人たち）
- 一つのスキンメッシュ（骨で動かすメッシュ）にまとめる。部位を骨に割り当てるので、膝・表情（まばたき・口・眉）を足しても 1 人 1 回の描画で済む（従来は 8 回）。
- 形：肩の丸み、胸と腰の絞り、肘・手首・膝、手（親指）。衣服：重ねた襟、袖口と広い袖、帯の結び目、裾の広がり。顔：鼻・耳・眉・口。人物ごとの髪型・体格・姿勢。
- 表情：まばたき、話している間の口の動き、聞いている間に少し眉を上げる（控えめ）。
- 足元：薄い接地の影。
- 色・質感・形の細かさの統一ルール（§3）。
- 位置・当たり判定・会話の距離・保存データは変えない。

### 2.5 その他
- 空の光の地面側（照り返し）を少し明るくし、軒下の木組みが読み取れるようにする。
- 住民の頭上に、近づくと名前を小さく出す（人を探しやすくする。物には出さない＝未発見の調べる所を先回りして教えない）。

## 3. 人物の統一ルール

| 項目 | ルール |
|---|---|
| 形 | 大きな面で形を作る（建物と同じく、細かな凹凸より輪郭）。円柱・球は 8〜12 分割まで。顔の部品は小さな面で、写実にしない |
| 色 | 服は彩度を抑えた中間色（建物の木・茅と並べて浮かない）。名前のある住民は色相で見分け、村の人たちはくすんだ色 |
| 質感 | 全員一つのマテリアル（頂点色・粗さ 0.82）。布の違いは色の明暗（襟・袖口・裾を少し明るく／暗く）で表す |
| 比率 | 頭は身長の約 1/5（親しみやすいデフォルメ）。体格・背丈は人物ごとに倍率で変える |

## 4. 完了条件
1. 屋外で上を見上げられ、サエ家の前から屋根の上部と傷みが見える。屋根を調べると傷んだ所が画面に入る
2. 傷みが遠目にも分かる（形の乱れ）。葺き替え後・三年後には出ない
3. 作業場に歩いて入り、中を歩いて、外へ出られる。壁・中の物はすり抜けない。閉じ込められる所がない
4. 人物の造形・表情・接地の改善。位置・会話・分岐・保存は変わらない
5. 描画負荷が大きく増えない（人物の描画呼び出しは減る見込み）
6. 型チェック・単体テスト・ブラウザテスト・本番ビルドが成功。1280×720・1024×640 で問題がない

### 5.2 作業場の方式の比較

| 案 | 長所 | 短所 | 判断 |
|---|---|---|---|
| 歩いて入れる（採用） | 「見えるのに入れない」違和感がなくなる。中の作業台・道具を近くで見られる | 判定・カメラ・床の高さの調整が要る | 採用。判定は配置データから作り、閉じ込められないことを単体テスト（到達可能性）とブラウザテストで確認 |
| 開口を柵・材料で塞ぐ | 実装が簡単 | 開いた正面と中が見えたまま入れない印象は残る。作業場の用途も伝わりにくい | 不採用 |

### 5.3 史実と創作
- 作業場の中の物（鉋・のみ・墨壺・のこぎり・木槌・曲尺・木挽き台・作りかけの梯子・縄と茅の束）は、一般的な木工の道具と屋根葺きの材料として置いたゲーム用の創作で、特定の道具の名前や使い方、白川郷の作業小屋の造りを史実として示すものではない（解説の画面には書き加えていない）。
- 屋根の傷みの表現（黒ずみ・苔・へこみ・欠け・乱れた茅）は見た目の創作。葺き替えの時期・頻度などの事実の説明には使っていない。
- 人物の服装は従来どおり、時代を特定しない素朴な形。襟は右前（着る人の左の身頃が上）にした。

### 5.4 描画性能（Intel Iris Xe、垂直同期なし、`GPU=1 npm run shots`）

| 場面 | Phase 6 | Phase 6.5 |
|---|---|---|
| 第1幕（屋外） | 238〜313fps／描画呼び出し 170〜235 | 205〜295fps／117〜177 |
| 屋根葺きの日 | 199〜248fps／262〜427 | 190〜234fps／181〜280 |
| サエ家の室内 | 246〜271fps／205〜233 | 212〜237fps／153〜193 |

- 人物は一人あたり 8 回から 2 回（体＋足元の影）の描画になり、描画呼び出しは 25〜35% 減った。三角形は一人あたり約 2,500〜2,800（分割数を統一ルールの範囲で抑えた）。
- FPS は Phase 6 よりやや低い範囲に出たが、同じ条件で続けて測った基準値が平均 243fps と 198fps と 20% ほど揺れた（この機械では熱などで計測ごとのばらつきが大きい）。人物の影・足元の影・茅の房をそれぞれ外して測っても、ばらつきより大きな差は見られなかった。極端な低下はないと判断したが、原因の切り分けは Phase 7 の性能の検証に持ち越す。
