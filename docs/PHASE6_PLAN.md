## 2. 方針

- **状態と描画の分離を保つ。** 設定・操作の案内・選択履歴・作業台の要点・音の音量計算は DOM／Web Audio に依存しない純粋な関数にして単体テストする。
- **未発見の情報を先回りして出さない。** 作業台の要点・比較・通知は、今の案と手帳にある情報だけから作る（見込みと同じく、知らないことは「分からない」）。
- **文字は小さくしない。** Phase 3.5 の文字の大きさ（変数）を維持し、詰めずに段階的に出す。
- **音は控えめに。** 長く聞いても疲れない音量・音色。会話中は環境音と音楽を下げる。ユーザーの操作（タイトルでのクリック・キー）の後に鳴らし始める。
- **セーブ形式は変えない。** 計画の決定時に付けていた葺き替えの記録を屋根葺きの日の終わりに移すため、屋根葺きの日の途中の古い記録は読み込み時に補正する。設定は別の保存領域。

### 5.2 音の一覧（すべて Web Audio API で合成。外部の音声ファイル・素材は使っていない）

| 種類 | 音 | いつ |
|---|---|---|
| 環境音 | 風（低くこもったノイズ、ゆっくり強弱）／水路のせせらぎ（水路に近いほど大きい）／鳥の声（ときどき、左右に散らす）／囲炉裏の火とはぜる音（室内） | 常に（会話中・画面を開いている間は下げる） |
| 足音 | 土の道・板の間（室内）・橋の板で音色を変える。走ると少し強い | 足が地面に着くたび |
| 音楽 | 五音音階の爪弾き（村：間をあけて短い句、屋根葺きの日：少し速く、三年後：少し陰りのある音階、タイトル・結末：静かな持続音を添える） | 常に（会話中は大きく下げる） |
| 操作音 | 項目の移動・決定・画面を開く（紙のすれる音）・会話の送り | 操作のたび（控えめ） |
| 出来事 | 手帳の記録（小さな鈴 2 音）・案が増えた（3 音）・約束・結帳を開く（帳面をめくる音と木の音）・計画の決定・時間の経過（余韻の長い鈴） | その場面 |
| 作業の音 | 屋根の上で茅を叩く音。屋根の上の人数が多いほど間隔が短く、作業の場から離れると小さい | 屋根葺きの日 |

音量：全体・音楽・環境音・効果音を別々に調整、ミュート（設定画面と M キー）。最初のクリック・キーの後に鳴り始める（ブラウザの自動再生の制限）。

### 5.3 カメラの初期構図（計測）

代表位置から、サエ家の屋根の最も高い点が画面のどこに来るかを測った（画面の上端＝1.0。1.0 を超えると切れる）。

| 構図 | 橋の南（開始地点） | 橋の北 | 広場 |
|---|---|---|---|
| 以前（見下ろし 0.42・10m・注視点 1.5m・画角 50°） | 1.88 | 2.44 | 2.59 |
| 採用（見下ろし 0.16・13m・注視点 2.3m・画角 55°） | 0.95 | 1.25 | 1.32 |

開始地点ではサエ家・伊助家の屋根が棟まで入る。広場の目の前では、大きなサエ家の棟までは入らない（ホイールで離れると入る）。主人公は画面の中央よりやや下に来る。会話中は注視点を顔の高さに下げる。

### 5.4 描画性能（Intel Iris Xe、垂直同期なし、`GPU=1 npm run shots`）

| 場面 | Phase 5.5 | Phase 6 |
|---|---|---|
| 第1幕（屋外） | 237〜304fps／描画呼び出し 161〜235 | 238〜313fps／170〜235 |
| 屋根葺きの日 | 224〜249fps／262〜425 | 199〜248fps／262〜427（199 は 1 場面だけ。同じ計画のほかの場面は 234〜246） |
| サエ家の室内 | 224〜288fps／203〜230 | 246〜271fps／205〜233 |

- Phase 6 で描画するものは増やしていない（UI は DOM、音は Web Audio）。屋外の FPS は Phase 5.5 と同じ範囲で、Phase 5.5 で出た 5〜10% の低下からさらに下がってはいない。
- 屋根葺きの日の作業の進み具合は、0.05 刻みで屋根の色を計算して取っておく（初めてその段階になったときだけ計算する）。
- 撮影は音を鳴らさない状態で行っている（操作がないため）。音の処理は描画とは別に動く。
