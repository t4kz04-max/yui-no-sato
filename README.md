# 結の約束

白川郷の「結（ゆい）」に着想を得た、ブラウザで遊ぶ短編 3D 探索・会話アドベンチャーです。

架空の山村「楓沢」を歩いて住民の話を聞き、それぞれの事情を知ったうえで、合掌造りの屋根葺きの段取りを一緒に考えます。
話しかければ誰でも手伝ってくれるわけではありません。住民の事情を知ると判断が変わる、という体験を中心にしています。

- 想定プレイ時間：初回 20〜30 分
- 対象環境：PC のブラウザ（Chrome などの最新版、キーボードとマウス）
- 舞台・人物・出来事はゲーム用の創作です。実在の文化・歴史との区別は、ゲーム内の解説と `docs/GAME_DESIGN.md`（B 節）に記しています。

## 操作方法

| 操作 | キー |
|---|---|
| 移動 | W A S D（矢印キー） |
| 走る | Shift |
| 話す・調べる | E |
| 会話を送る・決める | E・Enter・クリック |
| 選択肢を選ぶ | ↑↓・数字キー |
| 手帳 | Tab |
| ポーズ・設定／会話をやめる | Esc |
| 見回す | マウスのドラッグ |
| 寄る・離れる | マウスのホイール |
| 音を消す | M |
| 操作一覧を隠す | H |

会話や調査を終えるたびに、進行がブラウザに自動で記録されます（ポーズ画面から記録・再開もできます）。

## 開発

必要なもの：Node.js（20.19 以降または 22.12 以降）と npm。

```powershell
npm install          # 依存のインストール（初回のみ）
npm run dev          # 開発サーバー → http://localhost:5173/
npm run build        # 型チェック＋本番ビルド（dist/）＋出力物の検査
npm run preview      # 本番ビルドの確認 → http://localhost:4173/
npm test             # 自動テスト（Vitest）
npm run check        # 型チェック＋自動テスト＋本番ビルド＋出力物の検査
npm run test:browser # ヘッドレス Chrome による動作確認（Chrome が必要）
npm run test:preview # 本番ビルドでの動作確認（Chrome が必要）
```

技術構成：TypeScript・Vite・Three.js。3D の形と模様はすべてコードで生成しており、外部の画像・モデル素材は使っていません。
